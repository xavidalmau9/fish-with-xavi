# Fish with Xavi

Land-based youth urban fishing adventures in Miami-Dade County, Florida.

A single-page marketing + booking site for **Fish with Xavi** — guided shoreline fishing trips for kids (peacock bass, snook, tarpon and more) across Miami's canals, lakes, bridges and beaches.

## Pages
- `index.html` — landing page: hero, Meet Xavi story, pricing, species, safety, how-it-works, booking calendar, FAQ.
- `waiver.html` — full liability waiver with e-sign acknowledgment form.
